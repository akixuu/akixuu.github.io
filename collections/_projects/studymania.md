**StudyMania** is a Discord bot for making study sessions less lonely. Voice chats, a study timer, trivia, and a leaderboard so friends can keep each other from drifting off.

This was my **first hackathon** — **vsHacks!** in 2022. I didn't win anything, but it was probably the first place I learned to store user data for real. I had only dabbled with APIs before... :P

### How it works
Commands in Discord drive the bot. Sessions and scores land in MongoDB; the bot hands back timers, trivia prompts, and leaderboard rankings so a server can run a light study competition without leaving the chat!
