**Neuromatch Academy** is a three-week computational neuroscience
program. I took the 2025 Computational Neuroscience course (July 7–25) — daily
Python tutorials plus a pod research project.

### Project
Our group worked with **Kai Miller's Memory N-back** electrocorticography (ECoG)
dataset: intracranial recordings from a working-memory task from patients with epilepsy. We focused on **spectral analysis** — looking at how frequency-band power in the neural
signal relates to memory load.

### What the program covers
The curriculum mixes data-driven analysis with mechanistic models. Roughly:

**Week 1 — modeling & machine learning**
- Model types: what / how / why questions you can ask with a model
- Model fitting and generalized linear models (encoding & decoding)
- Dimensionality reduction
- Deep learning as a more flexible encoding model

**Week 2 — signal processing & dynamical systems**
- Modeling practice (how to scope a real project)
- Signal processing and time series, including Fourier analysis and spectra
- Linear systems, biological neuron models, and networks of neurons

**Week 3 — stochastic processes & causality**
- Bayesian decisions and hidden dynamics over time
- Optimal control and reinforcement learning
- Network causality: when something is causal vs. only correlated

Most days were tutorials in Python (NumPy, SciPy, matplotlib) plus several
hours of project time. The last day was project presentations.
